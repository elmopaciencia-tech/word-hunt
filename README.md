# Word Hunt Unlimited

An endless GamePigeon-style Word Hunt that runs in any browser and works as a Telegram Mini App.

**Play:** https://elmopaciencia-tech.github.io/word-hunt/

- Swipe across letters (or type on desktop) to find words
- 80 s, 2 min, or untimed Zen rounds on 4×4 or 5×5 boards
- See every word on the board when the round ends
- "Play specific letters" loads any board, such as one from GamePigeon

Single self-contained `index.html`. Dictionary: [ENABLE word list](https://github.com/dolph/dictionary).
